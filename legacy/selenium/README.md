# 旧版 Selenium 校园网自动登录脚本

> 本目录存放早期基于 **Selenium** 模拟浏览器操作的校园网自动登录脚本，仅供历史参考和技术比对，**不推荐日常使用**。  
> 当前推荐使用根目录下基于 `requests` 的新版脚本（速度更快、配置更简单）。

## 简介

该脚本通过 Selenium 控制 Edge 浏览器，自动访问校园网登录页面，完成以下操作：
- 从桌面 `账号.txt` 读取学号和密码
- 自动选择py对应运营商
- 自动填写账号、密码并点击登录

##文件说明

本目录包含以下脚本文件，分别对应不同运营商的硬编码版本（账号密码均从桌面 `账号.txt` 读取，但运营商后缀已固定）：

| 文件名 | 对应运营商 |
|--------|-----------|
| `unicom.py` | 中国联通（@unicom） |
| `cmcc.py` | 中国移动（@cmcc） |
| `telecom.py` | 中国电信（@telecom） |
| `keda.py` | 校园网（@keda） |

>这些脚本的运营商后缀已**硬编码**在代码中，如需切换运营商，请直接运行对应文件，无需手动修改代码。

## 快速开始（使用 setup.bat 一键配置）

1. 进入 `legacy/` 文件夹，双击运行 **`setup.bat`**。
2. 脚本会自动检测 Python 环境，并询问是否安装 Selenium 及 WebDriver Manager。
3. 按提示输入你的学号和密码，脚本会自动在桌面生成 `账号.txt`。
4. 配置完成后，直接运行 Selenium 脚本即可。

## 其他注意事项

### 浏览器响应慢
- 开机后 Edge 弹窗较慢，建议先**手动打开一次浏览器**，再运行脚本，可显著加快速度。

### 元素定位超时
- 如果页面加载慢导致运营商未自动选择，可调整脚本中的等待时间：
  ```python
  
  wait = WebDriverWait(driver, 0.5)   # 将 0.5 改为 1、3 或 5
  
  ```

### 元素定位说明
- 页面元素可能因 JS 动态加载或结构变化而变化，脚本使用了多种 CSS 选择器作为备选方案，增强了兼容性。

### 依赖库（由 setup.bat 自动安装）
- `selenium`
- `webdriver_manager`
